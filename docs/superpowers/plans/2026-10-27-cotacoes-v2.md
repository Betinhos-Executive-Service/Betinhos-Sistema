# Cotações V2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cotação como fila própria (sem tarefa), com avisos de urgência e preço pronto, botão "Enviei", lembrete de 2 dias úteis e motivo de perda obrigatório em lista.

**Architecture:** Regras puras novas em `quoteNotifications.ts` (quem avisar, quando, com que chave de dedupe). Os stores (mock e Dataverse) deixam de criar tarefa na cotação e passam a gravar notificações ligadas à cotação na tabela existente `cr40f_plannernotificacao` (nova lookup `cr40f_cotacao`). O lembrete é gerado pelo cliente ao carregar as cotações, com dedupe diário.

**Tech Stack:** React 19 + TS strict (`apps/shell`), Vitest, Dataverse Web API, PowerShell (schema DEV).

**Spec:** `docs/superpowers/specs/2026-10-27-cotacoes-v2-design.md`

**Pré-requisito:** as fases 2 e 3 da migração (`docs/superpowers/plans/2026-10-26-planner-no-shell.md`) concluídas nesta branch: `apps/shell/src/pages/planner/{domain,data,components,views}` existem em TS com os testes da V1.1 verdes. Os caminhos abaixo seguem esse molde; se a fase 3 nomeou um componente de outro jeito, use o equivalente (mesma responsabilidade).

## Global Constraints

- Obrigatórios na criação: solicitante, texto do pedido, prazo.
- 5 colunas mantidas: Nova · Em análise · Aguardando informação · Cotada · Respondida ao cliente (+ Histórico).
- Cotação nova não cria tarefa. Tarefas já ligadas a cotações ficam como estão (não migrar dados).
- Avisos só pela notificação do Planner (`cr40f_plannernotificacao`, sininho). Sem Teams, e-mail ou WhatsApp novos.
- Destinatários: urgente → membros da equipe "Financeiro" (`resolveIdByName(TEAM_TABLE, …, "Financeiro")`, já existente); preço pronto e lembrete → criador da cotação.
- Lembrete: 2 dias úteis após o envio, sem decisão.
- Motivos de perda: `Preço`, `Fechou com outro`, `Desistiu`, `Sem resposta` (obrigatório).
- Aceite só registra a opção; não cria reserva.
- DEV primeiro; PROD congelado até o Renan liberar. Schema só por script com `-ConfirmProd` para PROD.
- pt-BR, sem gradiente, tokens do `@betinhos/ui`.

```ts
import { addBusinessDays, lastProposalSentAt } from './quoteDomain';
import { notificationDedupeKey } from './notifications';
import type { Quote } from './types';

export type QuoteNoticeType = 'quote_urgent' | 'quote_ready' | 'quote_follow_up';
export type QuoteNotice = { quoteId: string; recipientEmployeeId: string; type: QuoteNoticeType; title: string; message: string; referenceDate: string; dedupeKey: string };

export const LOSS_REASONS = ['Preço', 'Fechou com outro', 'Desistiu', 'Sem resposta'] as const;

const notice = (quote: Quote, recipientEmployeeId: string, type: QuoteNoticeType, title: string, referenceDate = ''): QuoteNotice => ({
  quoteId: quote.id, recipientEmployeeId, type, title, message: `${quote.code} · ${quote.title}`, referenceDate,
  dedupeKey: notificationDedupeKey({ recipientId: recipientEmployeeId, taskId: quote.id, type, referenceDate }),
});

export function urgentNotices(quote: Quote, financeIds: string[], today: string): QuoteNotice[] {
  if (quote.status !== 'Nova' || quote.deadline?.slice(0, 10) !== today) return [];
  return financeIds.map((id) => notice(quote, id, 'quote_urgent', 'Cotação para hoje'));
}

export function readyNotice(previous: Quote, next: Quote): QuoteNotice | null {
  if (previous.status === 'Cotada' || next.status !== 'Cotada' || !next.creatorEmployeeId) return null;
  return notice(next, next.creatorEmployeeId, 'quote_ready', 'Preço pronto para enviar');
}

export function followUpNotices(quotes: Quote[], today: string): QuoteNotice[] {
  return quotes.flatMap((quote) => {
    const sentAt = lastProposalSentAt(quote);
    if (quote.status !== 'Respondida ao cliente' || !sentAt || !quote.creatorEmployeeId) return [];
    if (addBusinessDays(sentAt.slice(0, 10), 2) > today) return [];
    return [notice(quote, quote.creatorEmployeeId, 'quote_follow_up', 'Cobrar decisão do cliente', today)];
  });
}
```
